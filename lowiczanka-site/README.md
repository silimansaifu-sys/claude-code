# Łowiczanka Supermarkt — website

Static single-page site for **Łowiczanka Supermarkt**, a Polish/Eastern-European
supermarket at H. Bavinckstraat 5–9, 3555 GS Utrecht (Zuilen).

## Files

- `index.html` — single page, Dutch with Polish accents
- `styles.css` — Łowicz folk-art inspired palette (red / yellow / green on cream)

## Run locally

Just open `index.html` in a browser, or:

```sh
python3 -m http.server 8000
```

then visit <http://localhost:8000>.

## Hosting

Drop the folder into Netlify, Vercel, Cloudflare Pages, or GitHub Pages —
no build step required.
